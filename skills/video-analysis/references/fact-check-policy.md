# AI 补充解释与联网核查隔离规范

> **读取角色与时机**：仅由主会话在撰写笔记末尾**独立“AI 补充解释”区域**（且需要核对工具最新版本、仓库迁移或官方原生能力）时按需读取。

## 1. 严格隔离与防幻觉红线

- **独立声明**：本区域内容必须置于独立章节（如 `## AI 补充解释与联网核查对比（独立区域，非原视频内容）`），并在开头加显式声明说明与原视频直接讲述内容严格隔离。
- **严禁反写污染**：不得将 AI 联网查到的新版本号、新仓库名或替代方案悄然写回原视频“知识点精讲”或“原声实录”中冒充博主原话；若原视频提到的仓库已更名或功能已过时，仅在独立核查表中对照指出。
- **禁止凭记忆编造**：
  - 执行了联网检索（如 `search_web`）时，必须标注检索年月与明确的参考资料 URL。
  - 若处于离线环境或用户未要求联网核查，仅作必要术语与原理延伸，并明确标注“未执行外部联网核查”，严禁猜测当前最新版本号、命令参数或 GitHub 链接。

## 2. 推荐对照结构（涉开源工具 / 技术方案时）

1. **原视频描述 vs 最新实况 / 官方对比核查表**：
   - 列：`工具/模块 | 原视频描述 | 网上最新实况与官方对比（含检索日期） | 核查结论`
2. **核心实操补全与安全边界**：
   - 如官方原生替代能力、安装前置条件与安全注意事项（明确区分社区方案与官方原生方案）。
3. **参考资料来源**：
   - 仅列出本轮真实访问/检索确认过的 URL 或本地官方文档路径。
