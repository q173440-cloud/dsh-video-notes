# 多模态切片核图与 ASR 校对规范（仅 Subagent 读取）

> **读取角色与时机**：**仅由主会话派发的切片 `research` 子代理读取**。主会话全程严禁直接读取本文件、严禁批量读取全片关键帧或全量原始 ASR。

## 1. 输入清单

你将收到主会话分配的单个时间切片清单文件绝对路径（如 `.../work/slices/slice_01.txt`），其中包含：
- 当前时间段（约 60–120 秒）的全部原始字幕片段 `[start - end]: text`；
- 当前时间段内的全部关键帧截图绝对路径列表 `[时间点 MM:SS (ts)] <path>`。

请先使用 `read_file` 读取分配给你的 `slice_XX.txt`。

## 2. 多模态视觉看图覆盖标准（质量零降级）

使用 `read_file` 直接查看关键帧图像，重点提取**代码、终端输出、命令/参数配置、GitHub 仓库名、公式、板书、图表、总结对比表与 UI 操作步骤**，并与字幕口述交叉印证：

1. **常规密度（本切片 ≤ 12 张关键帧）**：逐张 `read_file` 查看所有非重复关键帧。
2. **高密度抽帧（本切片 > 12 张，如 `--baseline-interval 4 --scene-threshold 0.2`）**：执行**两阶段核图**：
   - **第一阶段（必看锚点）**：均匀抽读时间锚点帧（覆盖本切片首尾与中段），**以及**所有对应话题切换、章节横幅、信息卡片、代码/终端/配置弹窗、对比表格、总结图，以及 ASR 出现疑似同音错词或中英混读前后的关键帧（每 90 秒切片一般核验不少于 7–10 张，保证全片关键节点 100% 覆盖）。
   - **第二阶段（变化补帧）**：若相邻两张锚点帧之间画面主题、文字、图表或 UI 状态发生变化，必须补读中间帧，直到确认没有遗漏任何画面事实、命令行参数或仓库标识。

## 3. 事实核验与主客观区隔准则

- **精确证据锚定**：每项关键画面事实与操作步骤，必须同时给出秒级时间戳 `[MM:SS]` 与精确关键帧文件名（格式：`[关键帧: frame_pts_00003561.jpg @ 01:58]`）。
- **忠实原文与同音纠错**：摘录口播必须保留原始 ASR 听写状态（绝不把润色稿冒充原话）；对照画面直出文字与上下文，建立 ASR 同音错字/英文术语正误对照。
- **主客观分离**：将工具机制、参数、界面演示等**客观事实**，与 UP 主/博主的推荐倾向、打分、情绪化评价等**主观观点**（标注 `【UP主观点】` / `【主观评价】`）严格分开。
- **缺口如实上报**：若存在画面模糊/被遮挡、语速过快未听清、字幕静默跳段或口播与画面口径冲突，必须记录具体时间段与疑难帧绝对路径。

## 4. 固定紧凑回传契约（严格控制 1–2 KB / 片）

**严禁把整段原始 ASR 原文或无关寒暄贴回主会话**。请严格按以下 6 段结构输出你的回传摘要：

```markdown
### 切片摘要 [MM:SS - MM:SS]（核验 X / 总 Y 帧）

1. **带时间戳大纲与客观事实**：
   - `[MM:SS - MM:SS]` 主题/步骤说明 [关键帧: frame_pts_xxxxxxxx.jpg @ MM:SS]
2. **画面原文核实（术语/仓库/代码/参数/数字/表格）**：
   - 列出画面直出的精确拼写与关键数值（附关键帧名）
3. **原始口播精选（1–3 句原样未润色 ASR）**：
   - `[start.xs - end.xs]`：`原始听写文本`
4. **ASR 错词与专有名词校对表**：
   | ASR 原听写词 | 校对准确词 | 时间戳 | 关键帧 / 上下文依据 |
   |---|---|---|---|
5. **主观观点与评价标记**：
   - 【UP主观点 / 主观评价】`[MM:SS]` ...
6. **引用的关键帧清单与疑难复核帧**：
   - 引用帧：`frame_pts_...jpg`（列明文件 basename 即可）
   - 需主会话复核的疑难帧：无（若有模糊或口径冲突，贴出 1–2 个精确绝对路径及疑问点）
```
