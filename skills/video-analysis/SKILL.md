# 视频多模态分析与笔记生成规范

本 Skill 指导 Agent 自动化获取视频资源、结合字幕转写与关键帧画面，产出高质量结构化复习笔记。

## 执行流程

1. **探测元信息 (`video_inspect`)**：
   - 调用 `video_inspect` 传入 URL 或本地路径。
   - 识别视频来源、单集/合集、分 P 范围（单视频无明确要求绝不自动展开全部合集）。
   - 向用户简要说明视频标题、时长及待处理范围。

2. **获取、预处理与资产复用 (`video_prepare`)**：
   - 对指定条目调用 `video_prepare`。
   - **已有资产优先复用**：若条目已存在完整的 `source.json`、`transcript.json` 与关键帧 `metadata.json`，工具自动复用已有产物，跳过重复下载与媒体转写。
   - 仅当明确需要强制重跑（如 `forceRebuild: true`）或本地产物缺失时才触发实际下载转写。

3. **分段多模态理解 (`video_read_slice` + 视觉观察)**：
   - 调用 `video_read_slice` 读取有界字幕分段与对应的关键帧画面批次。
   - 对画面中出现的代码、图表、参数、控制台输出、板书和操作步骤进行事实提取。
   - **必须将画面事实与口述事实结合，记录带精确时间戳的证据**。
   - **画面事实必须精确关联具体关键帧文件名（例如 `[关键帧: frame_pts_00003561.jpg @ 01:58]`）**。

4. **结构化笔记生成与保存 (`video_save_note`)**：
   - 编写整集详细复习 Markdown 笔记，并调用 `video_save_note` 保存。
   - 单集笔记严格遵守如下格式结构与分层准则：
     - **元数据**：标题、来源链接、作者/发布时间、时长、处理范围与状态。
     - **核心主题与学习目标**：简明扼要说明本集解决的问题。
     - **带时间戳的章节大纲**：按逻辑结构梳理时间轴节点。
     - **原始口播与字幕实录精选**：若摘录口播，必须保留未经美化的原始听写状态，严禁将整理润色稿冒充为逐字实录。
     - **专有名词与正误校对表**：若 ASR 存在同音错别字或专有名词偏差，以结构化表格呈现原听写词、校对词、时间戳及关键帧证据。
     - **知识点精讲与操作流（客观事实）**：结合画面细节（参数、代码、公式、操作流程）与口述逻辑，每项操作必须有秒级时间戳及画面关键帧引用。
     - **UP 主主观观点与评价（观点区）**：明确标注为【UP主观点】或【主观评测】，绝不将作者主观喜好、打分或特定环境局限写成既定事实。
     - **复习索引与要点提炼**：关键考点与核心结论。
     - **已知缺口与回看提示**：画面被遮挡、语速过快未听清、或模型未确信的细节，如实标记时间位置并建议回看。
     - **AI 补充解释（独立区域）**：背景延伸、术语补充说明，与原视频观点和事实明确区分。
     - **处理来源记录**：字幕类型（官方/本地ASR）、采样设置、复用记录等。

5. **合集索引更新与用户概览**：
   - 若为多分 P / 合集，逐集处理完成后更新索引文件。
   - 在聊天回复中提供清晰简练的笔记摘要和保存文件位置。
